This is a **template**, not legal advice. Replace every `TODO:` block
with values specific to your company. Have a lawyer review the result
before going to production.

## Files to wire up

The UI template doesn't ship a `/terms` route — same pattern as
[privacy](/topics/privacy/):

1. Create `apps/ui/src/features/legal/TermsPage/TermsPage.tsx`.
2. Register the route.
3. Link from the sign-up form ("by signing up, you agree to our terms"
   pointing to `/terms` on your fork).
