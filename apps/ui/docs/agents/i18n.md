# i18n

Read when adding user-facing strings, errors, toasts, or
aria-labels.

`react-i18next` is wired through `<I18nProvider>`. Strings live in
`src/lib/i18n/locales/<locale>/common.json`.

```tsx
const { t } = useTranslation();
<h1>{t("auth.login.title")}</h1>
<p>{t("dashboard.welcome", { name: user.name })}</p>
```

No hardcoded user-facing strings in JSX. The lint rule has a
heuristic that flags bare `>Submit<` text in JSX. Errors, toasts,
aria-labels — all through `t()`.
